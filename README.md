# 国家队 ETF 观察站

面向宽基 ETF 的公开行情监控页。使用腾讯财经报价和东方财富历史成交额，观察 12 只核心 ETF 的量能与外内盘方向。

[打开监控网页](https://xkqin.github.io/national-team-etf-monitor/)

## 功能

- 页面可见且开启自动刷新时，每 20 秒请求最新报价。
- 五分钟同刻成交额与过去最多 20 个完整交易日比较，至少需要 5 个历史样本。
- 历史数据由 GitHub Actions 采集，页面通过同源快照同步。当日五分钟成交额由腾讯分时累计额差分还原，避免浏览器直连历史接口的空响应问题。
- 云端历史接口失败时保留已验证的历史缓存，并用腾讯报价和分时继续补充当日数据。历史覆盖不足时保留旧快照，部署测试会阻止缺失历史数据的版本发布。
- 日内累计成交额、历史日成交额、指数分类、搜索和排序。
- 缺失、延迟与接口错误提示，直连失败时保留原时间戳数据。
- GitHub Actions 在工作日北京时间 交易时段每五分钟、15:10 更新快照并部署。调度可能延迟。新建仓库持续 60 天无活动时，GitHub 可能停用定时任务，可在 Actions 恢复。

## 计算口径

同刻倍数使用各 ETF 共同可用且已经结束的五分钟区间。盘中保守排除当前尚未结束的一分钟，午休和收盘按交易时段截止。历史日需包含 09:35、15:00 和至少 48 个唯一五分钟记录，排除不完整首日。

外内盘差估算为 `成交额 × (外盘量 − 内盘量) / (外盘量 + 内盘量)`。缺少方向数据时显示缺失。池内涨跌按当日成交额加权。行情时间差超过 3 分钟或有缺失时暂缓综合信号。

观察规则由本站设定。倍数达到 1.3 时标记放量观察，达到 1.8 且外内盘差占比至少 8% 时标记重点观察。这些指标是量价推断，交易账户身份、真实净申购和实际机构持仓需依赖独立披露。

观察池参考 2025 年半年报相关汇金增持报道，选取沪深 300 四只、上证 50 一只、中证 500 一只、中证 1000 四只、科创 50 一只和创业板一只。当前持仓应核对最新基金报告。

历史活动图使用真实成交额。每日份额变化和机构持仓指数需要额外、连续的份额及披露数据，本站目前展示的指标范围见页面口径。

## 本地运行

需要 Python 3.11+，运行测试另需 Node.js 22+。应用无运行时依赖。

```sh
python scripts/collect.py
npm test
npm start
```

打开终端显示的本地地址。GitHub Pages 使用 `public/` 目录，由 `.github/workflows/pages.yml` 部署。

## 数据来源

- [腾讯财经行情](https://gu.qq.com/sh510300)
- [东方财富行情](https://quote.eastmoney.com/sh510300.html)
- [证券时报汇金 ETF 历史披露报道](https://www.stcn.com/article/detail/3316601.html)

公开访问接口可能限流或变更。数据原始时间、云端快照时间与覆盖率均在页面显示。页面未打开时，仅云端快照按工作日计划更新。

页面每分钟同步云端快照，云端在交易时段每五分钟尝试采集腾讯分时并部署。每天 15:10 尝试从东方财富校对历史档案。可使用 `python scripts/collect.py --refresh-archive` 手动校对。
