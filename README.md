# 国家队 ETF 观察站

盘中实时判断「国家队今天进场了没有」。跟踪中央汇金在 2025 年基金年报中被披露为持有人的 23 只宽基 ETF，看量能、主动买卖、IOPV 溢价和分钟级放量脉冲。

[打开监控网页](https://xkqin.github.io/national-team-etf-monitor/)

## 页面

- **实时结论**：大标题直接回答进场与否，下方五项「进场证据」逐项点亮；仪表、成交额、放大倍数、主动净买入、加权涨跌、加权溢价率随行情每秒更新。
- **盘中走势**：沪深300 指数、全池累计成交额对同时点均值、每分钟成交额与放量脉冲，同一时间轴；末端每秒随实时行情延伸。右侧为单只 ETF 的分钟级异动流。
- **分组**：七个指数组各自的放大倍数、主动净买入与涨跌，点击筛选明细。
- **明细**：23 只 ETF 的价格、涨跌、成交额、放大倍数、主动净买入、溢价率与分时迷你图，可搜索、排序。

## 刷新

- 交易时段（北京时间 09:15–11:30、13:00–15:00）每秒请求一次腾讯实时行情。交易所 Level-1 快照约 3 秒一跳，页面在 1 秒内反映。
- 11:30 与 15:00 之后再取几次确认最终数据，然后自动暂停；午休、收盘后、周末与休市日不请求，13:00 与次一交易日 09:15 自动恢复。无需手动刷新。
- 同一只 ETF 只接受时间更新的报价，避免不同行情服务器之间的回跳。
- 逐分钟分时每 60 秒更新，腾讯分时与东方财富分时互为备份，失败源冷却 5 分钟。

## 计算口径

- **放大倍数** = 今日实时成交额 ÷ 前 20 个完整交易日同一时刻的平均累计成交额（20 日均额 × 同时点进度）。5 分钟区间内部按近几个交易日主力 ETF 的真实逐分钟成交分布插值到秒；开盘后 5 分钟内不计算。
- **主动净买入** = 成交额 ×（外盘量 − 内盘量）÷（外盘量 + 内盘量）。
- **溢价率** = 现价 ÷ 交易所 IOPV − 1，按成交额加权。
- **放量脉冲**：全池 1 分钟成交额 ≥ 同时段均值 3× 且 ≥ 1 亿元（单只 ETF ≥ 4× 且 ≥ 0.5 亿元）；集合竞价分钟不计。
- **结论**：≥ 1.8× 且净买入占成交 ≥ 8% 为「疑似在上班」；≥ 1.3× 为放量观察；其余为常态。行情缺失、延迟或基线不足时暂缓结论。
- **进场证据**：全池 ≥ 1.3×；沪深300 四只合计 ≥ 1.5×；净买入占比 ≥ +3%；加权溢价 ≥ +0.10%；沪深300 指数低于昨收时出现放量拉升脉冲。

所有阈值为本站规则，所有结论均为公开行情的量价推断。交易账户身份、真实申购赎回与机构持仓以基金定期报告为准。观察池是 2025 年报的历史持有标签，不代表当前持仓。

## 数据

- 实时行情：[腾讯财经](https://gu.qq.com/sh510300)（浏览器直连）
- 分时：腾讯分时、[东方财富](https://quote.eastmoney.com/sh510300.html)分时（浏览器直连，互为备份）
- 同时点基线：东方财富 5 分钟线与日线，由 GitHub Actions 采集为同源快照 `public/data/snapshot.json`，收盘后校对
- 观察池来源：[中央汇金 2025 年末 ETF 持仓报道](https://finance.eastmoney.com/a/202603313690167766.html)

## 本地运行

需要 Python 3.11+，运行测试另需 Node.js 22+。应用无运行时依赖。

```sh
python scripts/collect.py
npm test
npm start
```

GitHub Pages 使用 `public/` 目录，由 `.github/workflows/pages.yml` 部署；部署前测试会阻止缺失历史数据的版本发布。
