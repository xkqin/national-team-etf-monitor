  • 同刻倍数 = 当日已完成区间累计成交额 ÷ 前最多 20 个完整交易日同刻均值，至少需要 5 日样本。1.3× 为放量观察，1.8× 且外内盘差占比 ≥ 8% 为重点观察。阈值为本站规则。
  • 外内盘差估算 = 成交额 ×（外盘量 − 内盘量）÷（外盘量 + 内盘量）。方向分类受撮合、套利、对冲与数据口径影响。
  • 实时行情来自腾讯财经公开接口，页面可见且自动刷新开启时每 20 秒请求一次。交易状态按北京时间工作日时段和行情时间推定，节假日或行情超过 3 分钟未更新会标记延迟。
  • 历史日线与五分钟基线由 GitHub Actions 从东方财富初始化，并在收盘后校对。盘中由腾讯分时补充，同时保留历史缓存。页面同源读取云端快照。当日五分钟成交额由腾讯分时累计额差分还原，每 5 分钟更新。量能比较使用全池共同可用的已结束区间，并标明截止时间。
  • GitHub Actions 在工作日北京时间 交易时段 每五分钟尝试更新云端快照，并在 15:10 再次更新。任务可能受调度延迟和接口可用性影响。页面会优先直连，失败时保留带原始时间戳的快照。
  • 部分 ETF 缺失或行情时间差超过 3 分钟时，显示可用子集成交额并暂缓综合信号。历史图仅合计 12 只均有记录的日期，当前未收盘交易日用浅色柱标明。
  • 数据源为公开访问接口，可能延迟、限流或变更。页面会披露连接状态、行情时间及覆盖率。源代码和计算逻辑可在 GitHub 查看。
